# Web/app học tập — Khoa học tự nhiên 7, Bài 21

**Bài 21: Khái quát về trao đổi chất và chuyển hoá năng lượng**
Môn Khoa học tự nhiên 7 — Chương VII: Trao đổi chất và chuyển hoá năng lượng ở
sinh vật, Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập
(10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng SVG tương tác: Mặt Trời chiếu quang năng xuống cây xanh; cây lấy khí
carbon dioxide và nước, thải khí oxygen, chuyển quang năng thành hoá năng dự
trữ; dòng năng lượng truyền sang gà để vận động (hoá năng → cơ năng, nhiệt
năng). Có chế độ ban ngày/ban đêm và thanh cường độ ánh sáng.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai21.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — Apps Script Web App nhận điểm trắc nghiệm, ghi vào Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (1376×768) + logo giáo viên.
